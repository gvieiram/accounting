# Admin — direção visual

> **Vazio por decisão.** A direção estética foi adiada; o harness veio primeiro.

O que já está decidido e vale desde já:

- **Shell** — sidebar sempre visível no desktop (colapsa pelo trigger interno); sem header
  no topo; pill flutuante no mobile abrindo a sidebar como bottom drawer. Container:
  `gap-6 px-4 pt-6 pb-24 sm:gap-8 sm:px-6 sm:pt-6 sm:pb-12`.
- **Estados** — contrato dos quatro em [`README.md`](./README.md).
- **Formato deste arquivo** — frontmatter YAML (`colors`, `typography`, `rounded`,
  `spacing`, `components`) + prosa. Token por referência, nunca hex inline.

A preencher quando a direção for definida: tipografia, densidade, tabela, formulário,
feedback, movimento.

Referências de dashboard não foram escolhidas. Os exemplos avaliados (Apple, Cursor) são
análises de landing page — servem ao [`public.md`](./public.md), não a esta superfície.
